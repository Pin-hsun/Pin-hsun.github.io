MindVoyage is an AI-driven dementia rehabilitation system combining generative AI, computer vision, and human-centered design to enhance cognitive therapy. Personalizing tasks with real-world object interaction provides adaptive feedback and game-based daily training. An Avatar guide ensures an engaging, stress-free experience, enhances memory recall, and reduces caregiver burden.

Cooperating with neurologists, product designers and software engineers, I implemented real-time object detection models to determine whether the users are performing the rehabilitation tasks correctly. We also integrated large language models that users can interact with to generate images and content to create personalized tasks.
